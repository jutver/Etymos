Thu muc goc repo: E:\Etymos\Etymos   (moi lenh chay tu day)

Thanh phan:
  - Backend  : FastAPI (backend/), chay bang Docker, http://localhost:8000
  - Web      : apps/web   (nguoi dung), Vite, http://localhost:5173
  - Admin    : apps/admin (quan tri),   Vite, http://localhost:5174

Luu y: .env*, .env.local chua secret, da nam trong .gitignore. KHONG commit.


=====================================================================
1. CHUAN BI (chi lam 1 lan)
=====================================================================
npm install

# Env cho backend (Docker doc file nay):
cp .env.backend.example .env.backend        (Git Bash)
copy .env.backend.example .env.backend      (PowerShell / cmd)

Cac key trong .env.backend:
  SUPABASE_URL                Supabase project URL
  SUPABASE_SERVICE_ROLE_KEY   service-role key (chi dung o server)
  SUPABASE_JWT_SECRET         JWT secret cua Supabase
  GEMINI_API_KEY             API key Gemini
  ALLOWED_ORIGINS            origin duoc phep CORS. Chay local phai co:
    http://localhost:5173,http://127.0.0.1:5173,http://localhost:5174,http://127.0.0.1:5174

# Env cho frontend: tao file .env.local o thu muc goc (Vite doc file nay):
VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_SUPABASE_URL=<cung gia tri voi SUPABASE_URL>
VITE_SUPABASE_PUBLISHABLE_KEY=<publishable/anon key trong Supabase:
                               Project Settings -> API>
# TUYET DOI khong dung service-role key cho bien VITE_* (se lo ra trinh duyet).
# Sau khi sua .env.local phai restart dev server.


=====================================================================
2. CHAY BACKEND (Docker)
=====================================================================
# Co GPU NVIDIA (docker-compose.yml + backend/Dockerfile):
docker compose up -d --build

# Khong co GPU (docker-compose.cpu.yml + backend/Dockerfile.cpu):
#   phai bat feature flag gemini_metadata_extraction va gemini_ai_rewrite
docker compose -f docker-compose.cpu.yml up -d --build

# Kiem tra (lan dau khoi dong mat ~1-2 phut de tai model embedding)
curl http://localhost:8000/api/health
docker compose ps
docker compose logs -f api

# Kiem tra GPU trong container (chi ban GPU):
docker compose exec api python3 -c "import torch; print(torch.cuda.is_available())"

# Sau khi sua code backend (container KHONG co --reload):
docker compose up -d --build

# Sau khi chi sua .env.backend (nap lai env, khong build lai):
docker compose up -d --force-recreate

# Dung / go bo (them -f docker-compose.cpu.yml neu dung ban CPU):
docker compose down          (giu volume)
docker compose down -v       (xoa ca volume)

Luu y: chi chay MOT trong hai ban (GPU / CPU) vi cung ten container va
port 8000. Doi ban thi `down` ban dang chay truoc.

=====================================================================
4. LOI THUONG GAP
=====================================================================
- Loi CORS tren trinh duyet: origin cua web chua nam trong ALLOWED_ORIGINS
  (.env.backend). Them vao roi: docker compose up -d --force-recreate
- Khong dang nhap duoc: thieu VITE_SUPABASE_PUBLISHABLE_KEY trong .env.local
  (thieu thi web dung key gia "demo-publishable-key").
- Web goi sai backend: kiem tra VITE_API_BASE_URL, roi restart dev server.
- Port 5173 / 5174 dang bi chiem: Vite dung strictPort nen se bao loi thay vi
  tu doi port; tat process dang giu port do.
- Backend "unhealthy" luc moi khoi dong: dang tai model embedding, doi va
  xem `docker compose logs -f api`.
